# Papa's Pomodoro Pal

A time management and focus timer web app—and my first AI app—built with **TypeScript**, **CSS**, and **JavaScript**.

🌐 **Live App:** [https://father-focus-timer.lovable.app](https://father-focus-timer.lovable.app)

## Overview

`papa-s-pomodoro-pal` is a focus and time management application created by [Thanmaya Rishi](https://github.com/thanmayarishi), exploring AI-assisted development and agentic workflows.

### Built With
- **TypeScript** (98.1%) — Application logic and state management
- **CSS** (1.2%) — Styling and layout
- **JavaScript** (0.7%) — Client-side runtime behavior
- **Bun** — Package management and runtime configuration (`bun.lock`, `bunfig.toml`)
- **Vite** — Build and development server (`vite.config.ts`)
